# Studio Machine

Studio Machine is a personal AI fitness coach project that uses activity, biometric, and recovery data to analyze training load, consistency, race readiness, and daily workout recommendations.

The goal is to build a data-driven coaching system that helps answer questions like:

- Am I training consistently?
- Am I increasing mileage safely?
- Am I recovering enough?
- What should I do today?
- How ready am I for my next race?

## Project Vision

Studio Machine is designed to act like a personal fitness intelligence layer. It will combine training activity data, biometric signals, and recovery trends to generate simple, useful coaching insights.

The long-term goal is to build a system that can review my recent training, understand my current fitness goals, and provide daily recommendations based on both performance and recovery.

## Data Sources

Initial data sources may include:

- Strava activity exports
- Garmin activity and health data
- Heart rate data
- Sleep and recovery metrics
- Running, lifting, boxing, and other workout history

## MVP Goals

The first version of Studio Machine will focus on Strava activity data and basic training analysis.

The MVP will include:

- Importing and cleaning activity data
- Weekly mileage and training volume trends
- Run frequency and consistency tracking
- Pace and heart rate trends
- Long run progression
- Basic training load insights
- Rule-based daily coaching recommendations

## Future Features

Future versions may include:

- Garmin recovery and biometric data integration
- HRV, resting heart rate, and sleep analysis
- Race readiness scoring
- Fatigue and injury risk flags
- AI-generated daily coach summaries
- Streamlit dashboard
- Personalized training recommendations

## Tech Stack

Planned tools:
